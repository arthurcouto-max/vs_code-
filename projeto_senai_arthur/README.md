# Blog de Rock

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um blog sobre rock e metal.

O blog apresentará conteúdos como notícias, bandas, álbuns, curiosidades e recomendações musicais. O objetivo é criar um site organizado, simples e de fácil navegação.
## Estrutura Analítica do Projeto

### 1. Documentação

- Definir o objetivo do projeto
- Criar o arquivo README.md
- Criar a EAP do projeto
- Organizar as tarefas no Kanban

### 2. Front-End

- Criar a página inicial
- Criar o menu de navegação
- Desenvolver a página de bandas
- Desenvolver a página de notícias

### 3. Design

- Escolher as cores do site
- Escolher as fontes
- Organizar imagens e textos
- Criar o layout das páginas

### 4. Testes e Publicação

- Testar os links do site
- Corrigir erros encontrados
- Verificar o funcionamento das páginas
- Publicar o projeto no GitHub

## Organização do Kanban

As tarefas do projeto serão organizadas nas seguintes colunas:

- Backlog
- A Fazer
- Em Andamento
- Em Teste ou Revisão
- Concluído

## Como Executar o Projeto

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
